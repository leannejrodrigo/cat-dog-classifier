# Cat vs Dog Classifier

A deep learning image classification project built using TensorFlow, Streamlit, and transfer learning with MobileNetV2.

## Features
- Image upload
- Cat vs Dog prediction
- Confidence scores
- Streamlit web app
- Transfer learning

## Technologies
- Python
- TensorFlow
- Streamlit
- MobileNetV2

## Run App

```bash
streamlit run app.py
```

## Live Demo

## Model

This project uses transfer learning with MobileNetV2 for image classification.
